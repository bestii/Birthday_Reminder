# 08 — Person detail & event edit

**What to build:** Tapping a card opens the person detail view — full-width image hero, back button, person ellipsis (edit person / assign to group / delete person), overlapping name/group/zodiac card, and one tappable card per event (Birthday card shows Born on / Next birthday / Turns / Zodiac). Tapping an event opens its edit screen (date, notes, type, per-event year toggle) where delete also lives.
