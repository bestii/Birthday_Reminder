- [ ] Date format presets: `MMM D, YYYY` (default), `D MMM YYYY`, `DD/MM/YYYY`; takes effect across the app.
- [ ] Theme: Light / Dark / System default (default System); takes effect across the app.
- [ ] Zodiac toggle, off by default; controls the detail-view zodiac chip.
