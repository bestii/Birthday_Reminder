# 05 — Manage groups

**What to build:** The Manage Groups screen — list groups with name + people count, add via `+`, delete via trash (immediate), and an empty state. Reachable from the Home FAB (and later Settings). People are not listed or assigned here; assignment lives in the person detail view.

**Blocked by:** 02 — Database schema & repository

**Status:** ready-for-agent

- [ ] Manage Groups screen lists groups with name + people count.
- [ ] `+` creates a new group from a name input.
- [ ] Trash deletes a group immediately (with confirmation).
- [ ] Empty state reads "No groups yet. Tap + to create your first group."
- [ ] Groups persist to SQLite and are reusable by other screens.
